# Topic Search｜从上传文献到确定科研选题

Topic Search 是一个逐步引导科研选题的 Codex 技能。它从你手头的一篇或几篇相关论文出发，先帮你整理证据，再找候选问题、核对是否已有研究回答，最后结合你的实际条件给出定题建议。适合正在探索方向、准备开题，或想判断一个候选题是否值得做的人。

## 安装与使用

1. [下载仓库 ZIP](https://github.com/Zoey-lovereading/skill/archive/refs/heads/main.zip)并解压，把整个 `topic-search` 文件夹复制到个人 Codex 技能目录。默认路径为 macOS/Linux 的 `~/.codex/skills/`，Windows 的 `%USERPROFILE%\.codex\skills\`。如果设置过 `CODEX_HOME`，放到该目录下的 `skills/`。安装后应能在 `skills/topic-search/SKILL.md` 找到技能入口。
2. 在 Codex 的新对话里输入：

   > 用 $topic-search 带我从上传论文开始，一步步找到可行的科研选题。

3. 按提示在**自己的对话里**上传论文 PDF、全文或补充材料。先上传一篇也可以。论文不需要上传到这个 GitHub 仓库。已有文献表、候选题或查新结果时，可以直接附上，让技能从相应步骤接着做。

## 工作流程

| 步骤 | 技能会做什么 | 你会得到什么 |
| --- | --- | --- |
| 1. 上传论文并生成文献表 | 逐篇核对研究问题、方法、测量、结果、图表及相关附录。 | 八列文献表，关键事实附页码、章节或图表号；缺失内容标注“未报告”或“无法核实”。 |
| 2. 横向比较，找研究方向 | 按共同问题归组，比较对象、指标、分析单位和研究设计，检查单篇论文的局限是否已被其他论文补上。 | 推荐方向、备选方向，以及各方向的文献依据和未答问题。 |
| 3. 拆成候选研究问题 | 围绕同一方向，追问换一个情境是否成立、在哪些条件下不同、现有证据能否解释原因等。 | 几个可比较的候选问句，每个注明研究价值和最低证据要求。 |
| 4. 反向查新 | 优先寻找最可能已经回答同一个问题的论文，核对正文、图表和附录。 | 最接近的研究、重合与差异，以及保留、缩小或调整题目的建议。未检出不等于没人研究过。 |
| 5. 审查可行性并建议定题 | 按学科和研究设计，核对材料、测量、方法、时间、经费和适用的权限要求。 | “可定题／先验证再定题／缩题后可做／当前条件下不宜做”的判断，以及最优先的验证任务和通过标准。 |

每一步都有可核对的产出，并说明如何进入下一步。查新时没有联网能力，就给出可复制的检索式并标明“尚未检索”。最后会分别说明**选题的新意**和**你在现有条件下能不能做**。
