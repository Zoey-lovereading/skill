# 文献表与判读口径

可复制到表格的八列（制表符分隔）：

```tsv
文献（作者、年份）	研究问题	研究对象与范围	核心变量及测量	数据与研究设计	主要发现	证据边界	候选研究问题
```

- 默认一篇一行；同篇有多项独立研究且回答不同问题时可拆行并编号。文献列可附题名、DOI 或可核实链接。
- 对象与范围记地区、时间、分析单位；跨文献比较时可将这些拆列。变量记操作定义。设计记数据来源、样本和实际比较；发现保留相关效应量与不确定性（若报告），附页码、章节或图表号。
- 分清“未报告”和“无法核实”；分清作者指出的局限和按设计推断的证据边界。候选问题注明“待查证”。相关不写成因果，两篇一显著一不显著不等于结论冲突。
- 横向比较时，检查是否问同一问题、证据是否匹配、结果是否能相互印证、结论适用到哪里。优先找会改变判断的表外证据，再补回原表。

假设示例：北京街区研究报告绿量与夏季白天地表温度的关联；一项多城研究包含南京但只报告总体关联；南京另一项研究测的是空气温度。它们合起来仍未直接回答“南京街区绿量与夏季白天地表温度的关联有多大”。反向优先查多城论文正文或附录中的南京单独估计，同时核对指标、时段、分析单位。若已有可比的南京结果，撤回“缺本地估计”的主张，再判断是否还有值得检验的边界。
