# 科研选题的四段 AI 指令

每段可单独复制。连续对话可让 AI 沿用已有输入；换对话时附上相应的论文、文献表、候选问题或资源信息。方括号内换成自己的内容。

## 1. 上传原始论文，让 AI 解析并生成文献表

```text
我会上传一篇或多篇论文 PDF、全文或补充材料。我还没有整理好的表。请先逐篇解析：从引言或研究目标确认论文问什么，从方法确认对象、指标和设计，从结果、图表和附录核对关键发现与比较，再根据设计判断证据边界。最后把各篇解析结果汇总成一张文献表，使用以下 8 列：
文献（作者、年份）｜研究问题｜研究对象与范围｜核心变量及测量｜数据与研究设计｜主要发现｜证据边界｜候选研究问题。

一篇论文默认一行；多个独立研究回答不同问题时可拆行。写明对象、地区、时间和分析单位，保留指标的实际定义。主要发现只记与研究问题有关的结果；原文报告了效应大小及不确定性时一并记录。区分关联和因果、未发现显著差异和证据显示差异很小。

关键事实后标注章节、页码或图表号。证据边界区分作者的说明与根据设计作出的判断。材料中未交代写“未报告”，相关内容不可见写“无法核实”。只有摘要时标注“仅据摘要”，遇到扫描不清或附件缺失时指出是哪篇、缺什么。候选问题写成一句可检验的问句，标注“待查证”。只依据所给材料。输出带表头的 TSV：8 列用制表符分隔，每格不换行，方便粘贴到表格。
```

## 2. 横向比较，找方向和候选问题

```text
根据我的文献表 [附表] 和研究条件 [兴趣、已有数据或材料、方法、时间]，帮我从相关研究中提炼可供选择的研究问题。

按共同问题或现象分组，注明论文或行号。比较对象、指标、分析单位、设计和结果，写清每组哪些结论可互相印证、哪些不宜直接比较、哪些单篇局限已被表内其他研究补上。归纳值得追问的方向，说明各自的表内证据和剩余疑问。

从一个最有依据的方向生成 2–3 个不同的候选问句。可以追问换情境是否成立、在哪些条件下不同、为何发生，或现有证据能否区分关联与因果。每项输出：核心问题｜表内依据与未答部分｜答案的价值｜最低所需证据｜应优先查证的新意主张。把“表内未见”标作待查证，不当作领域空白。没有足够依据时少列，并写明需补什么材料。
```

## 3. 反向查新，找最能削弱新意的论文

```text
我的候选问题是 [可检验的问句]，暂定新意是 [具体新增的问题、比较、方法或证据]，已有文献见附件。请假设这个问题可能已有人回答，主动找能削弱这项新意的研究。

先界定什么算直接回答，拆出必须匹配的对象、场景、指标、分析单位、比较或设计。用 Google Scholar、Google 或能实际访问的学术数据库，从核心概念宽搜，再加入关键条件定向查找。用中英文同义词、替代术语，多地区或上位地区研究，以及最接近文献的参考文献和后续引用补漏。记录实际平台和检索词；不能联网时只给可复制检索式，注明“尚未检索”。

把最强反例放在第一位。给出题名、年份、可核实的 DOI 或链接、重合与差异，并核对关键比较是否见于方法、结果、图表或附录，标注原文位置。只看得到摘要时写“仅据摘要，待核实”。分别判断“已有直接证据”“部分覆盖”或“本轮检索未找到直接证据”。说明应保留、缩小或撤回哪条新意，并按原表表头列出适合补录的文献。不要把未检出写成“首次”或“无人研究”。
```

## 4. 做定题前可行性审查

```text
请根据已经提供的学科或领域、核心问题、文献表、查新结论、拟用设计和研究资源，判断这个题现在是否可以定题。最新条件是 [已拿到的数据或材料、设备与技能、指导或协作、时间经费、权限]；未给的信息标为“未知”，不要视为已落实。

先复述问题和结论目标（如描述、比较、因果判断、解释、理论证明或工程验证）。选最接近的同领域同类设计作参照，说明它们依赖什么证据，再设定本题必须满足的条件。不同学科用适用的标准；不要编造统一样本量或门槛。用“关键条件｜为何必要｜当前证据｜已确认/暂定/未知｜核实办法”列出硬条件，检查证据或材料、测量或论证、设计、技术和支持、时间经费、适用的伦理及权限。

分别报告新意与可行性，给出“可定题／先验证再定题／缩题后可做／当前条件下不宜做”之一。说明决定性依据，并给一个最小验证：做什么、什么算通过、没通过如何改题。如果缺少会改变结论的信息，先给条件式判断，最多追问 3 项，并明确最优先确认哪一项。
```
